# 創発の種 — 会社紹介資料

ゴールデンサークル（Why → How → What）で構成した、縦スクロール1ページの会社紹介。
**リンクで送って読んでもらう**用途が主。印刷でPDF配布もできる。

## ファイル

| | 内容 |
|---|---|
| `index.html` | **公開用の完成ファイル**（1ファイル完結・外部依存ゼロ）。これをそのままGitHub Pagesに置く |
| `src/part1.html` | 前半＝理念パート（表紙・WHY×3・HOW×2）。背景が「種→若葉→森」と深くなる |
| `src/part2.html` | 事業説明（課題・サービス概要・提供価値・3プラン・比較表・留意事項） |
| `src/part3.html` | 業種別できること（8業種タブ×24例）・末尾セクション・CTA |
| `src/build.py` | 3パートを統合し、フォントをサブセット取得して `index.html` を生成 |
| `src/logo-*.b64` | ロゴのbase64（ライト用／ダークテーマ用に文字色を反転したもの） |

## 編集の流れ

```bash
# src/part*.html を編集してから
python3 src/build.py
# → index.html が再生成される（要ネットワーク: Google Fontsからサブセット取得）
```

⚠️ `index.html` を直接編集しない。ビルドで上書きされる。

## 設計

- **前半で引き込み、後半で納得させる**。前半は1画面1メッセージ＋色の進行、後半はアイボリー基調の罫線グリッド。モードの切り替わりが目でわかる
- **CTAで読者に判断を要求しない**。「理念で選んでほしい」とは書かず、次の一歩（無料DX診断・60分相談）だけを置く
- **できないことを載せる**（大規模改修は対象外など）。誠実さがそのまま信頼になる
- フォントは Zen Maru Gothic を**使用文字だけサブセット化して埋め込み**。CDN参照なしで確実に丸ゴシックが出る
- 印刷時は業種タブを全展開し、濃い背景を白に落とす
